# `@blast-agents/shared`

Types, zod schemas and pure functions shared by the web app, the API and the workers. No Sui or network dependencies, so it is safe in the browser. Pricing rules live here, so every surface quotes the same numbers ([docs/ECONOMICS.md](../../docs/ECONOMICS.md)).

| Module         | Contents                                                                                                                                                                                                                                                                                                                                                                                 |
| -------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `activity.ts`  | Activity levels the user picks (`ACTIVITY_LEVELS`: Watchful, Steady, Active, Intense) and custom budgets (`ActivityChoice`, `resolveActivity`). The level sets decisions per day and reaction speed; there is no platform cap.                                                                                                                                                           |
| `models.ts`    | The curated `MODEL_CATALOG` (premium / standard / budget, OpenRouter slugs, prices, trading evidence), `MODEL_PRICES`, `reconcileCatalog` (checks live OpenRouter prices before a model is offered), `LEADERBOARD_ELIGIBILITY`                                                                                                                                                           |
| `pricing.ts`   | `PRICING` policy; `quotePlan` (daily price from cost, ≥30% margin after the 30% referral); `feeDrag` and `recommendPlan` (no minimum deposit, small vaults guided); `quoteFeeTerms` (fee cap = 3× plan price), `planChangeNeedsSignature`, `feeCapHeadroom`; `decideDailyFee`; `aggregatePrice`, `checkDailyPriceMove`; `trialDaysFor`, `trialDecisionsPerDay`; `treasuryCurrencyReport` |
| `referrals.ts` | `REFERRALS` policy (30% of collected fees, lifetime, single level); `bindReferral` (anti-self-referral), `accrueReferrals`, `proposePayouts` (needs human approval), `describeReferral`                                                                                                                                                                                                  |
| `economics.ts` | Cost-model primitives: `costPerDecisionUsd`, cache hit ceiling and break-even, `dayEconomics`, `breakEvenVaults`, `lifetimeValueUsd`, `maxChurnForCac`, `annualFeeDrag`                                                                                                                                                                                                                  |
| `limits.ts`    | `OnChainLimits` (mirrors the Move `Limits`, MIST as strings), `RiskSettings`, `RISK_PRESETS` (Careful / Balanced / Degen), `settingsToLimits`, `DEFAULT_PRESET`                                                                                                                                                                                                                          |
| `fees.ts`      | `FeeTerms` (fee cap, treasury, free days) and `DEFAULT_FREE_DAYS`                                                                                                                                                                                                                                                                                                                        |
| `decision.ts`  | `VaultAction`, `Decision` and the strict `DECISION_JSON_SCHEMA` given to every model. Vaults only allow `buy` and `sell`; `join_opening_round` is rejected (SPEC §5.4.1).                                                                                                                                                                                                                |
| `api.ts`       | Request schemas for the API in SPEC §7 (`PrepareVaultBody` carries the plan and an optional referral code)                                                                                                                                                                                                                                                                               |
| `units.ts`     | `suiToMist` (exact decimal parsing), `mistToSui`, `formatSui`, `SUI_TYPE`                                                                                                                                                                                                                                                                                                                |

```ts
import { quotePlan, quoteFeeTerms, feeDrag } from "@blast-agents/shared";

const plan = quotePlan("claude", { level: "steady" }); // $1.01/day, up to 24 decisions
const terms = quoteFeeTerms(plan.priceUsdPerDay, suiUsd); // fee cap = 3× the price, in MIST
const drag = feeDrag(plan.priceUsdPerDay, vaultUsd); // { annualShare, band }
```

Run the tests with `pnpm --filter @blast-agents/shared test`.
